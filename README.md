# 하루 하나 쓸데없는 게임

하루 안에 기획하고 완성하는, 짧고 이상한 브라우저 게임 모음입니다.

## 규칙

- 게임 하나는 하루 안에 완성한다.
- 핵심 규칙은 하나만 둔다.
- 설치 없이 브라우저에서 바로 실행되게 만든다.
- 각 게임 폴더에 간단한 조작법과 한 줄짜리 기획 의도를 남긴다.

## 게임 목록

### 001. 복사기 각성시키기

스페이스바를 연타해 전력 부족 복사기를 10단계까지 각성시키는 게임입니다. 실패하면 1단계부터 다시 시작하며, 마지막 다이아몬드 종이는 2%의 결정화 확률을 뚫어야 합니다.

- 실행: [games/copier-soul-injector/index.html](games/copier-soul-injector/index.html)을 브라우저로 열기
- 조작: `Space` 연타
